# 03 Output schema definition — Feature Discovery

One record per capability: stable `FEAT-ID`; name; user outcome; primary actor; source `REQ-ID`; priority (`Must`, `Expected`, `Stretch`); workflow `WF-ID`; dependencies; acceptance behavior; evidence status; open question. The inventory must cover every in-scope requirement, link every must-have feature to a workflow, and distinguish a planned capability from an implemented one.

The competitor matrix has one row per platform and records public source URL, documented candidate and employer capabilities, Talentra comparison, and evidence limits. It supports a design hypothesis only; it cannot prove feature parity or superiority. Validate ID uniqueness, all referenced IDs, requirements coverage, and source dates before review.
